# Индивидуальный проект: практика по алгоритмам (100 задач)

Репозиторий содержит решения 100 практических задач с платформ спортивного программирования, распределённых по трём тематическим блокам.

## Цель проекта
Систематизировать изучение ключевых алгоритмических тем на практике и собрать открытое портфолио решений.
